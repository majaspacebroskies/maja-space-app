# Maja Space: update files

This folder holds the update files of the Maja Space apps (Android, Windows, Mac). Installed apps check
`update.json` here by themselves and update; there is nothing to do here for students.

**Get the app:** https://safistudyspace.netlify.app/

- Android phones and tablets (Android 7 or newer): [MajaSpace-latest.apk](https://github.com/majaspacebroskies/maja-space-app/raw/main/updates/MajaSpace-latest.apk) (version 10.3, content 10.3.0, published 2026-10-19).
- Windows and Mac: [the latest release](https://github.com/majaspacebroskies/maja-space-app/releases/latest).

What's new: Maja Space for Windows and Mac. Updates now come from the maja-space-app repository.

Every file here is signed with Maja Space's key. The apps ignore anything that isn't, so a changed or fake
file can't be installed through them.
