# Maja Space · app files

Finished app files of **Maja Space**, the study planner for Tamil Nadu State Board Class 12, and nothing
else: the source code is kept private. Everything here is built and minified from it.

**Download:** https://safistudyspace.netlify.app/, or directly:

| Device | File |
|---|---|
| Android phone or tablet (Android 7+) | [MajaSpace-latest.apk](https://github.com/majaspacebroskies/maja-space-app/raw/main/updates/MajaSpace-latest.apk) |
| Windows 10 / 11 | [MajaSpace-Setup.exe](https://github.com/majaspacebroskies/maja-space-app/releases/latest/download/MajaSpace-Setup.exe) |
| Mac with Apple Silicon (M1–M4) | [MajaSpace-mac-arm64.dmg](https://github.com/majaspacebroskies/maja-space-app/releases/latest/download/MajaSpace-mac-arm64.dmg) |
| Mac with Intel | [MajaSpace-mac-x64.dmg](https://github.com/majaspacebroskies/maja-space-app/releases/latest/download/MajaSpace-mac-x64.dmg) |

- `updates/`: what installed apps download (signed; see `updates/README.md`).
- `desktop/`: the files GitHub builds the Windows and Mac apps from; `.github/workflows/desktop.yml` builds,
  installs and tests them on Windows and Mac, then publishes them under Releases.
